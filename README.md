Task 4 - Breast Cancer Classification Using Logistic Regression

* Objective

To develop a binary classification model using Logistic Regression that predicts whether a breast tumor is Malignant or Benign based on diagnostic features from the Breast Cancer Wisconsin Dataset.

* Tools Used

Python

Pandas

NumPy

Scikit-learn

Matplotlib

* Steps 

Imported the Breast Cancer Wisconsin Dataset

Performed data exploration and preprocessing

Checked and handled missing values

Removed unnecessary columns

Converted target labels into numerical values

Selected input features and target variable

Split the dataset into training and testing sets

Applied feature scaling using StandardScaler

Trained a Logistic Regression model

Generated predictions on test data

Evaluated the model using:

*Confusion Matrix

*Precision Score

*8Recall Score

*8ROC-AUC Score

*Classification Report

Visualized the ROC Curve

Performed threshold tuning for better classification analysis

Plotted the Sigmoid Function used in Logistic Regression

* Dataset

Breast Cancer Wisconsin Dataset From Kaggle
